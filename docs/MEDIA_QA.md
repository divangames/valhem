# Медиафайлы VALHEM

При добавлении изображения или музыки указываем, где оно используется в игре. Исходники WAV и большие PNG хранятся в `assets`, а для сайта готовим компактные WebP или M4A/Opus. Путь к файлу добавляем в игровой код.

`node scripts/build-pages.cjs _site` собирает сайт: копирует основные файлы игры и все веб-изображения, аудио и шрифты из `assets`. Большие WAV-исходники не попадают на сайт, кроме WAV-резерва музыки меню.

`game-tools.bat --qa` проверяет локальные ресурсы, собирает временную копию сайта и убеждается, что все используемые медиа попали в неё. Также выполняются браузерные проверки ПК, мобильной раскладки и офлайн-PWA. После публикации `game-tools.bat --qa-live` проверяет ссылки на медиа на GitHub Pages; команда публикации запускает эту проверку автоматически.

Новый ресурс считается добавленным только после проверки его использования в игре, прохождения локального QA и проверки опубликованного URL после деплоя. Физический телефон проверяется отдельно от эмуляции.
