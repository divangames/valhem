# VALHEM Online Server

Первый серверный слой игры: здоровье сервиса, облачные сохранения, таблица рекордов и временные комнаты миров.

## Локальная проверка

```bash
npm install
npm test
npm start
```

Сервис слушает `127.0.0.1:8080`. Данные сохраняются в `data/valhem.json`; эта папка не попадает в Git.

## Переменные окружения

См. `.env.example`. В рабочем окружении API публикуется только через HTTPS-прокси. Node-порт не нужно открывать в интернет.

## Ограничение первого этапа

Комнаты, участники, сохранения и рекорды уже работают. WebSocket поднят для следующего этапа, но боевая синхронизация ещё не подключена. До серверной проверки игровых событий таблица рекордов считается предварительной.
