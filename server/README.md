# VALHEM Online Server

Серверный слой игры: здоровье сервиса, облачные сохранения, таблица рекордов, временные комнаты и WebSocket-транспорт сетевого боя.

## Локальная проверка

```bash
npm install
npm test
npm start
```

Сервис слушает `127.0.0.1:8080`. Данные сохраняются в `data/valhem.json`; эта папка не попадает в Git.

## Переменные окружения

См. `.env.example`. В рабочем окружении API публикуется только через HTTPS-прокси. Node-порт не нужно открывать в интернет.

## Сетевая модель

Хозяин комнаты является авторитетом игрового мира. Гость отправляет только управление и действия; хозяин рассчитывает бой и передаёт гостю снимки состояния. Сервер ретранслирует сообщения только между участниками одной комнаты.

До полной серверной проверки игровых событий таблица рекордов считается предварительной.
