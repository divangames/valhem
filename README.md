# VALHEM v1.0 «САГА»
Бесконечный викинг-роглайт в одном HTML-файле.

## Запуск локально
Запусти `game-tools.bat` и выбери пункт **1**, либо открой `index.html` вручную. Игра работает сразу; Service Worker и офлайн-режим требуют http(s).

В меню `game-tools.bat` также есть отправка изменений через commit + push, обновление GitHub Pages и открытие опубликованной игры.

## GitHub Pages
Деплой настроен через GitHub Actions и автоматически запускается после каждого push в ветку `main`.

Игра: https://divangames.github.io/valhem/

## itch.io
1. Zip: index.html + sw.js + icon.svg.
2. Upload → «This file will be played in the browser».
3. Обложка 630×500, скриншоты 1280×720 из игры (F12 → device toolbar для мобильных кадров).

## Мобильные
Игра рассчитана на горизонтальную ориентацию. При старте на поддерживаемых Android-браузерах запрашиваются полноэкранный режим и блокировка landscape; на iOS нужно включить системный автоповорот и повернуть устройство вручную. Если активный бой оказывается в портретном режиме, он автоматически ставится на паузу и продолжается только после возврата в landscape.

Авто-джойстик расположен слева, адаптивные кнопки и автоприцел — справа. Интерфейс учитывает вырезы экрана, системные панели и изменение высоты адресной строки. Переключатель сенсорного управления в настройках: АВТО/ВКЛ/ВЫКЛ.
