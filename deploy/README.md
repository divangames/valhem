# Развёртывание VALHEM Online

Рабочая схема:

- клиент: GitHub Pages;
- API: `https://213.139.209.107/api/`;
- WebSocket: `wss://213.139.209.107/ws`;
- Node.js: только `127.0.0.1:8080`;
- внешний HTTPS и проксирование: существующий Nginx;
- данные: `/var/lib/valhem-online/valhem.json`;
- systemd-сервис: `valhem-online.service`.

Секреты и приватный SSH-ключ не находятся в репозитории.

После каждого серверного деплоя обязательны:

1. `npm test` локально.
2. Проверка синтаксиса Nginx до перезагрузки.
3. Проверка состояния `valhem-online.service`.
4. Проверка `GET /api/health` через публичный HTTPS.
5. Создание комнаты, вход второго игрока, выход и закрытие комнаты.
6. Проверка сохранения и чтения таблицы рекордов.
7. Просмотр последних журналов сервиса.

Существующий сервис на VPS использует корневой маршрут `/`; конфигурация VALHEM добавляет только `/api/` и `/ws` и не должна изменять остальные маршруты.
